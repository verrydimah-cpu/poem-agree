A tiny Node program that writes one short poem to `entry.txt`: two agents who could each have acted alone meet at a crossroads, trade keys, and agree on a single plan — and the power to act, shared, comes back doubled rather than halved. The poem is five lines, under the bounty's 280-character limit, and the program is deterministic: every run writes the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
